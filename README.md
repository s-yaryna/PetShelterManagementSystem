# The Pet Shelter Management System
_The Pet Shelter Management System is a desktop application developed in Python using Object-Oriented Programming (OOP) principles. It is designed to replace inefficient, paper-based logging systems in veterinary clinics, animal shelters, and zoos with a centralized, secure, and modern digital solution._


## Benefits
_The advantages of the program are that it contains all information about all the animals that are in the shelter. This will help to better track, manage, analyse and store data about animals and prevent any problems with the loss of important information in emergency cases._

_Similarly, all data is in one place, so that users can access it from different devices at any time, rather than searching through archives for paper documents and certificates, which can often get lost and misplaced._ 

_Additionally, the advantage of the program is that the interface and functionality for a person is as simple as possible and provides the opportunity to add new animals to the system and specify details about them. Moreover, the system is using a graphical interface, not a console interface._

_The program has clear and understandable navigation and also a simple and convenient layout that helps users quickly orient themselves and work. The program is as thoughtful as possible and uses beautiful and minimalist designs so as not to distract the user from work and also contains all the necessary functions._

## Target audience and users
_The target audience of the program is all roles of employees of a veterinary or zoo company who deal with animals and monitor their indicators, data and care for them._

_These users do not have clear age restrictions, but they will be approximately from 18 years old to 65 years old, so the system and program should be suitable in design and mechanics for this age range._

_Users are also not limited by gender, so the program will be as neutral as possible and will use a minimalistic design that will contain animal themes to suit the company.
Users will add new animals and enter all the necessary data that will be stored and displayed in the system and then work with this data._ 

## Nature of interactivity
_Interaction in the program for the user occurs in such a way that various graphic elements are used, such as:_
* _buttons_
* _input fields_
* _scroll bars_
* _navigation bars
which help navigate and interact with the program._

_It is also important to note that there are a lot of checks and validation of the entered data to avoid errors in calculations and there are also lots of instructions for the user so that he understands what the program requires.
Also, in case of errors or incorrect input, an error message will be displayed also with the data and an explanation for the user._
