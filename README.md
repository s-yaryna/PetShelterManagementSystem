# PetShelterManagementSystem
The Pet Shelter Management System is a desktop application developed in Python using Object-Oriented Programming (OOP) principles. It is designed to replace inefficient, paper-based logging systems in veterinary clinics, animal shelters, and zoos with a centralized, secure, and modern digital solution.
